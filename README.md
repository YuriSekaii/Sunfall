# Sunfall

Co-op roguelike survival-defense game built with **Godot 4.7** + **Blender**.

Stranded after a plane crash on an uncharted bio-weapon island, you have ~10 days until rescue. Scavenge tools, food, and lab materials by day (or risk dark caves and basements where monsters stay active), then build and repair your defenses before the sun drops and the horde hunts.

## Quick Start

- **Play:** Double-click `Play_Game.bat` (auto-unpacks bundled Godot from `engine.zip` on first run).
- **Edit:** Double-click `Open_In_Godot_Editor.bat`.
- **Update:** Double-click `Update_Game.bat` (`git pull origin main` + asset re-import).
- **Save / Push:** Double-click `Push_To_GitHub.bat`.
